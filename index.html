R-loop Binding Protein Prediction Database

RLBPPredDB: an integrated portal for RLBP prediction, annotation, and candidate prioritization.

RLBPPredDB provides a focused interface for RLBP annotation browsing and practical data access. All runtime files are distributed with the repository and can be served locally without a backend.

Current Scope

Dataset currently emphasizes Human and Mouse records for fast iterative updates.

  • Annotation table with keyword, species, review-status, and confidence filters.
  • Data Access page with database location and contact details.
  • Help page with common RLBP questions and usage notes.
  • Static local deployment through a lightweight HTTP server.
