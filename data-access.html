Data Access

This page documents where RLBPPredDB database files are stored.

Database Location

  • Local runtime files: rlbp_annotations.json, rlbp_annotations.csv, and rlbp_prediction_template.csv
  • Keep these files in the repository root beside the HTML, CSS, and JavaScript files.

Database Files

  • rlbp_annotations.json
  • rlbp_annotations.csv
  • rlbp_prediction_template.csv

Scope

  • Current species: Human and Mouse.
  • The packaged runtime database contains 37,077 reviewed records: 20,075 human and 17,002 mouse proteins.
  • The strictly curated SaProt-650M-AF2 + MLP ensemble provides scores for 37,077 records: 20,075 human and 17,002 mouse proteins.
  • All retained human annotation records have a strict-model score; no historical scores are mixed into this release.
  • The 401 human candidates are the untrained-pool subset scoring at least 0.98, not all database records above that threshold. The human empirical FPR target is not a mouse calibration claim.

Local Deployment

  • No backend service, build step, external folder, or private host is required.
  • The annotation page reads rlbp_annotations.json relative to the local site.
  • Start a local HTTP server as described in the repository README; do not open the HTML files directly with a file:// URL.
